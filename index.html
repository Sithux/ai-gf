How to Host Sachi on GitHub Pages

100% Free permanent web hosting for mobile & PC

Step 1: Save code locally

Save this entire webpage file as index.html on your computer.

Step 2: Upload to GitHub
  1. Go to GitHub.com and create a new public repository (e.g., sachi-ai).
  2. Click Upload an existing file and select your index.html.
Step 3: Enable GitHub Pages

In your GitHub repository, go to Settings ➔ Pages ➔ Set Branch to main ➔ Click Save.

🎉 Done! Your live link will be https://username.github.io/sachi-ai/. Works anywhere on phones & laptops!
